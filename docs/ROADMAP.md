# 项目路线图

## 阶段 0：数据冻结与质量检查

当前 `split_v1` 是后续实验的固定比较基准。每一张图片、JSON 和 TXT 都通过
`dataset_manifest.csv` 关联原始名称、新名称和数据划分。

训练前还应抽查以下问题：漏标、重复实例、相邻果实粘连、轮廓穿过果梗、轮廓越界、
极小多边形以及同一果实被拆成多个实例。建议建立 `annotation_issues.csv`，修订标注后
发布 `split_v2`，不要静默覆盖 `split_v1`。

当前 1285 张照片的背景和拍摄装置较一致。这里的 test 适合衡量同分布性能，但不能充分
代表不同相机、光照、背景、品种、成熟度和采收批次下的泛化能力。后续应另采一批
`external_test`，整批隔离且不参与训练和调参。

## 阶段 1：重新训练可比较基线

必须重新训练。旧模型训练时使用过旧 train，并依据旧 val 选择过最佳轮次；如果把旧模型
直接拿来评估新 test，可能发生训练或模型选择污染。

基线应从通用 `yolo26n-seg.pt` 开始，而不是从旧 `best.pt` 继续训练。记录：代码版本、
依赖版本、GPU、随机种子、数据清单哈希、训练参数、每轮指标和最终权重。至少重复 3 个
随机种子，报告均值和标准差，避免把随机波动当成算法改进。

核心分割指标：Mask mAP50-95、mAP50、Precision、Recall；辅助指标包括漏检数、重复 mask、
粘连实例、边界 IoU、小目标性能、单图推理耗时和显存占用。

## 阶段 2：实例导出与 OpenCV 特征

对每个实例保存：

- 原图 ID、新图 ID、split、模型版本、实例 ID、置信度；
- 二值 mask、透明背景 crop、外接矩形和轮廓点；
- 面积、周长、凸包面积、长轴、短轴、长宽比、圆度、实心度、偏心率；
- RGB/HSV/Lab 的均值、标准差、分位数；
- 高光比例、暗斑/异常色比例、颜色均匀度和纹理统计；
- mask 是否触边、实例是否过小、轮廓是否退化等质量标志。

像素面积和像素长度不能直接当作真实物理尺寸。如果目标是毫米或平方毫米，需要在同一
成像平面加入标尺/标定板，保存像素到实际尺寸的标定系数，并控制相机距离和透视。

OpenCV 特征优先从人工真值 mask 上验证计算正确性，再切换到预测 mask；否则分割误差会和
特征算法误差混在一起。特征表以“一行一个果实实例”为粒度，禁止只保留图片级平均值。

## 阶段 3：YOLO26 改进实验

先做错误分层，再决定改哪里：

- 小果/远距离漏检：分辨率、多尺度训练、小目标特征层或损失权重；
- 遮挡和粘连：实例边界质量、mask 分辨率、重叠样本增强；
- 光照和颜色变化：受控 HSV/亮度增强、白平衡与域增强；
- 背景误检：补充困难负样本；
- 边界粗糙：更高 mask 分辨率、边界损失或后处理对比。

每次只改变一个主要因素，保存基线与改进方案的参数量、FLOPs、速度、显存和精度。
正式结论应来自相同数据、相同预算、多个随机种子的消融实验，而不是只比较一次最好结果。

## 阶段 4：品质识别

当前标签只有 `wolfberry`，只能训练实例分割，不能直接训练优/劣或等级识别。若最终目标是
品质分级，需要先定义可复核的等级标准，并为每颗实例建立 `quality_label`。推荐先用分割 +
OpenCV/传统机器学习形成可解释基线，再与端到端分类或多任务网络比较。
