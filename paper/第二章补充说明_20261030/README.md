2026-10-30逐文件比较确认：两版图像ID完全一致，多边形坐标和顺序不变，7条等级变更，其中6条一级→三级、1条二级→三级。相应果梗属性修订记录见原版本说明。它是标注纠正，不能描述成模型或图像的“优化版”。

完整数据口径为：训练集使用V3，当前开发评价的验证标签使用valfix覆盖层，测试集使用V3。valfix目录只是验证标签覆盖层，不包含新的整套图像。

## 3. “2.1.1 研究对象与图像来源”可替换稿

本研究采用自行采集的枸杞图像，采集时间为2026年7月初，研究对象为来自宁夏的枸杞鲜果。原始数据由1285幅PNG图像及对应的JSON实例标注和TXT格式标签组成，图像分辨率均为1280×720像素。原始JSON中共包含5752条以“wolfberry”为类别的实例多边形标注。

代表性图像中可见白色容器背景，以及不同朝向的多个果实；部分样本存在果实接触及手、工具造成的局部遮挡。图像文件作为图像数量的统计单位，每个单独标注的果实区域计为一个图像实例。现有清单未保存实物果实唯一标识及经确认的采集批次关联，因此图像实例总数不等同于经核实的不同实物果实数量。

**作者补充事项（不直接混入上述正文）**：仍需明确拍摄地点、具体品种、相机/镜头和拍摄条件。只在获得实际信息后增加采集设备与环境段落；不要把“宁夏”直接写成拍摄地点，也不要补造具体日期、品种和光照设置。设备细节尚缺时，上述文字可作为当前可核实的替换稿，但采集方法段仍未完全定稿。
